3. Short Demonstration of the Working Application
Aap is demonstration script ke mutabiq application ko live test ya evaluate kar saktay hain:

Step 1: One-Click Launch
Root folder mein run.bat (ya V2 folder mein start.bat) par double-click karein:
System automatically MongoDB start karega (127.0.0.1:27017 with D:\mongodb-data).
Server aur Client start honge aur browser par automatically http://localhost:5000 open ho jayega.

Step 2: Live Feature Walkthrough
🔹 1. Module 1: Project Charter & Milestones
Charter & Plan Tab par jayein.
"Edit Charter" button dabayein: Project Name, Sponsor, Approved Budget (PKR 5.0M), Start Date, aur Objectives live edit ho saktay hain.
"+ Add Milestone" modal se naya delivery milestone enter karein (e.g. M6: Post-launch Warranty Support).
🔹 2. Module 2: Scope Management & WBS
Scope & WBS Tab par jayein.
Scope Gate Test: "+ Add WBS Element" open karein aur koi unapproved requirement link karne ki koshish karein. System validation rule show karega k unapproved requirement WBS ka hissa nahi ban sakti.
"+ Add Requirement" modal se nayi MoSCoW functional/non-functional requirement enter karein.
🔹 3. Module 3: Schedule, CPM & Gantt Chart
Schedule & Gantt Tab par jayein.
CPM Network table check karein: Early Start (ES), Late Start (LS), Total Float, aur Critical Path (isCritical) automatic calculate hota hai.
Update Progress Slider (0-100%): Kisi activity par click kar ke progress slider ko drag karein; system live schedule slippage recalculate karega.
🔹 4. Module 4: Cost Management & Earned Value (EVM)
Cost & EVM Tab par jayein.
Key Metrics: Planned Value (PV: 2.85M), Earned Value (EV: 2.23M), Actual Cost (AC: 2.85M), CPI (0.78), SPI (0.84), aur Forecast EAC (6.41M).
Threshold Alert: Jab CPI < 0.85 hota hai to system automatically RED warning alert banner trigger karta hai.
"+ Log Actual Cost" modal se nayi labor ya license expenditure add karein.
🔹 5. Module 5: Quality, Defects & Risk PDPC
Quality & Defects Tab par jayein:
"+ Log Defect" modal se bug report karein (Severity: Critical/Major/Minor).
"+ New Audit Review" se dynamic checklist criteria add karein (Pass/Fail toggles).
Risk & PDPC Tab par jayein:
5×5 Risk Matrix heatmap visual check karein.
PDPC Viewer open karein: Failure prevention chain (Goal → Technical Risk → Preventive Branch → Corrective Contingency) graphically render hota hai.
🔹 6. Module 6: Change Control (CCB) & Audit Report
Change Requests Tab par jayein:
CR-001 (AI Symptom Checker & Mobile App) par "Simulate Impact" click karein.
System before/after modal open karega: Budget PKR 5.0M → 5.8M, Deadline 20 Feb → 09 Mar.
"Approve & Baseline v2" click karein: System automatically Baseline v2 create karega aur status update karega.
Status Report Tab par jayein:
Executive monitoring document display hoga.
"Print / Export PDF" button click kar ke report print ya PDF mein export kar saktay hain.
