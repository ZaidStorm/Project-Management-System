4.4 Earned Value Management
We'll implement exactly the five requested indicators.
PV — Planned Value
How much work should have been completed according to the plan.
PV = Planned Budget × Planned Completion %

EV — Earned Value
How much budgeted value has actually been earned from completed work.
EV = Planned Budget × Actual Completion %

AC — Actual Cost
How much has actually been spent.
AC = Total Actual Expenditure

CPI — Cost Performance Index
CPI = EV / AC

Interpretation:
CPI > 1     Under budget
CPI = 1     On budget
CPI < 1     Over budget

SPI — Schedule Performance Index
SPI = EV / PV

Interpretation:
SPI > 1     Ahead of schedule
SPI = 1     On schedule
SPI < 1     Behind schedule
